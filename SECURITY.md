# Security Policy

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public GitHub issue, pull request, discussion, or commit.

Report security concerns privately through the [NextGenSwitch contact page](https://nextgenswitch.com/contact/) or email [support@nextgenswitch.com](mailto:support@nextgenswitch.com). Include a concise description, affected component, reproduction steps, potential impact, and any suggested mitigation.

Do not include real customer data, production credentials, private keys, API secrets, SIP passwords, call recordings, or unnecessary personal information.

## Response Process

The maintainers will review the report, confirm receipt when possible, investigate the affected versions, and coordinate remediation and disclosure. Response and remediation time depends on severity, reproducibility, and project resources.

## Deployment Responsibility

Security also depends on the operator's environment. Production deployments should use appropriate network controls, TLS, access restrictions, secret management, dependency patching, logging, monitoring, backups, and carrier protections. Change default or shared credentials before exposing any service.
