# Contributing to NextGenSwitch

Thank you for helping improve NextGenSwitch.

## Before You Start

- Search existing issues and pull requests before opening a new one.
- Use GitHub issues for reproducible bugs and focused feature proposals.
- Use the [NextGenSwitch contact page](https://nextgenswitch.com/contact/) for deployment, account, pricing, or private support questions.
- Do not include passwords, API keys, SIP credentials, phone lists, call recordings, logs containing personal data, or customer information.

## Development Workflow

1. Fork the repository or create a branch.
2. Keep each change focused on one problem.
3. Add or update tests when behavior changes.
4. Run the relevant test and formatting commands.
5. Update documentation for user-visible changes.
6. Open a pull request that explains the problem, the change, and how it was verified.

## Bug Reports

Include:

- A clear title and expected behavior
- The observed behavior
- Reproduction steps
- Operating system, PHP version, database, and deployment method
- Sanitized logs or screenshots when useful

Remove secrets and personal or customer data before sharing diagnostics.

## Pull Requests

A useful pull request includes:

- A concise summary
- The reason for the change
- Verification steps and results
- Compatibility or migration notes
- Screenshots for user-interface changes
